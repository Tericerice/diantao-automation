# 淘金币双11赚能量

运行入口：`run_taobao_energy.cmd`。复用现有 `device_connection.connect_with_retry`，不启动旧点淘任务调度器。

```powershell
# 从首页或活动页面进入并连续执行免费浏览任务
.\run_taobao_energy.cmd run --repeat 30

# 从淘宝首页“领淘金币”或活动主页面进入赚能量列表
.\run_taobao_energy.cmd enter

# 检查当前屏幕和文字坐标
.\run_taobao_energy.cmd scan

# 逐项处理当前屏幕内已确认的免费浏览任务，最多30轮
.\run_taobao_energy.cmd auto --repeat 30

# 指定一个任务；每轮返回复查累计次数是否增加
.\run_taobao_energy.cmd browse 好物随心逛 --repeat 3
```

- 首页支持按文字或内容描述定位 U2 `领淘金币` 控件。首页及进入淘金币后会关闭可唯一识别的“我知道了”“暂不”“稍后再说”“关闭弹窗”等提示；“取消”和普通关闭符号仅在已识别通知、物流提醒或版本更新提示时使用。每次关闭后重读页面，最多处理3层；按钮不唯一、连续弹出或未知页面则停止，不点击授权。兼容新版活动的“去赚能量”入口，并要求同时识别到“升级赛车拿钱”页面标识；只进入能量任务，不点击升级赛车。活动 WebView 无有效文本时，将 JPEG 截图发送至用户配置的 OCR 服务识别。
- 工作台启动及 `run`、`enter` 命令每次重新启动淘宝，确认首页后依次进入“领淘金币 → 去赚能量”，不沿用上次停留的页面。任务中途返回及到账复查不重启淘宝；`auto`、`browse`、`scan` 等单步命令保留从当前页面执行的用法。
- `run` 首轮后默认最多重新进入复核 **5次**，与一键任务的复核方式一致。每轮最多执行 `--repeat` 指定的任务数（上限30），复核时重新启动淘宝并扫描，本轮不再尝试的任务记录随轮次重置。首次无任务仍重新进入确认一次；复核轮无可执行白名单任务时提前结束。所有轮次共用本次运行时限，不延长60分钟限制。到账最多核对3次，每次记录前后数值；仍未增加且确认留在淘宝任务列表时，不记成功、本轮跳过该项并继续其他任务，下一复核轮可重试。未知页面、OCR故障、时限等异常仍保留现场停止。`--rechecks 0` 关闭复核，或设置0至5次；`auto` 默认不复核。
- 任务会动态改名、换序，每轮重新定位任务和同一行的“去完成”。搜索任务进入搜索页后，从预存常用词表轮换取词、清空输入框并输入搜索，再滑动浏览，不依赖页面推荐词。
- 自动模式扫描列表各页，按三梯队执行：**淘宝内任务 → 支付宝 → 其他应用**。处理白名单浏览任务及“看看#”主题，并领取解锁的累计任务奖励。
- 已验证的访问任务包括闪购、淘宝视频、淘宝成就页、蚂蚁森林、蚂蚁庄园、支付宝农场、支付宝金豆/红包页面，以及微博、闲鱼、快手、一淘、淘特、天猫购物红包。跨应用任务确认目标应用打开后立即返回淘宝，不再固定停留30秒；返回后核对累计次数或能量，50/50及累计奖励横幅暂时消失时也能按能量增量确认。
- 新增“去组队可加快升级”“你关注的商品都可抵”“搜一搜你喜欢的宝贝”和“拍立淘逛感兴趣的宝贝”。浏览时长按任务行的5秒/15秒要求加2秒余量；未识别到时使用 `--seconds`。搜索任务预存“固态硬盘、牛肉干、移动硬盘、牙刷、纸巾”，按次轮换输入并提交搜索；词表可在 `tools/taobao_energy.py` 的 `SEARCH_TERMS` 中修改。输入前确认搜索页面及唯一输入框；返回时兼容键盘和多层搜索页。拍立淘只停留浏览，不拍照、不选择或上传相册图片；页面报错时仍以返回后的实际到账为准。
- 跨应用只点击系统的“仅本次允许”或“打开”，不修改长期权限。未安装应用时查看任务入口后直接返回；遇到下载/安装页面不点下载、不安装，继续下一项。未确认到账的访问任务本轮不重复尝试。
- OCR与U2文字合并，保留原生控件可读文字；奖励动画遮挡进度时等待后重读。遇到未知授权、登录障碍或未知页面，保留现场交由人工检查。等级考试仅自动处理已验证的“进入比赛期后，想继续追赶对手”题，选择“A 及时邀请好友助力”；只提交答案，不发送邀请。题目或选项不匹配时停止，不猜答案。提醒订阅不自动处理。
- 升级赛车、趣味小游戏、积分兑换、购买、邀请等不进入自动浏览白名单；拍立淘仅放行上述已验证的任务名称。`tap`、`back`、`swipe`、`text` 是供已检查截图后的逐步操作使用的低层命令。
- 每次手动启动默认最多运行 **60分钟**，可用 `--run-minutes 90` 调整。也可用 `--deadline` 指定含时区的未来截止时间，该选项优先；时间已过或缺少时区时，在连接手机之前拒绝启动。
- 多设备连接时用 `--serial` 明确选择设备。仅连接一台时自动选择。

最近一次截图和 OCR 坐标保存在 `screenshots/taobao_energy/current.png`、`current.json`；`browse.png` 是返回前的浏览页。

管家日志显示环境准备、连接、任务名称/梯队、浏览等待、到账能量、跳过原因和结束汇总。正常运行不再输出整屏 OCR JSON，异常在管家中显示一行原因；完整识别数据和异常堆栈保存到 `logs/taobao_energy/日期-时间-进程号.log`，启动时会显示文件位置。显式执行 `scan` 仍输出 JSON，方便人工定位。启动器首次使用 uv 创建 `.venv-energy` 并安装依赖，之后直接复用固定环境；准备失败会显示原因，下次启动会重新准备。

启动管家的“Python脚本”分类中已注册 **淘金币双11赚能量**，执行 `run --repeat 30`，不会随管家启动自动运行。管家重启后载入注册表。重新注册：

```powershell
uv run --no-project python deploy/register_taobao_energy.py "<automation-butler目录>"
```

管家中的“启动”按钮发起一次运行，不随管家自动执行。运行时限从本次启动计算，不使用历史授权日期；这不代表聊天助手取得长期手机控制权。

## OCR 配置（本机或自有服务）

任务使用用户自己配置的 OCR HTTP 服务，不绑定腾讯云或作者的服务器。可以在自己的电脑上安装 OCR，或接入自有远程服务；本机安装及接手 AI 的部署步骤见 [README](../README.md#给使用者及接手本项目的-ai先准备自己的-ocr)。

首次配置将 `.env.example` 复制为 `.env`；已有配置时仅修改其中的 `DIANTAO_OCR_SERVER_URL`，也可通过同名环境变量设置。本机示例为 `http://127.0.0.1:8888/predict_ocr`。接口接收表单字段 `image` 的 JPEG 截图，返回 `code=200`、`data` 文字块及原图中心坐标。其他 OCR 引擎需适配相同契约。服务不可用时停止，不会偷偷改用作者或其他服务。实际服务地址和凭证不提交到仓库。
