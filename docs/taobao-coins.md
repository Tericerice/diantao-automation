# 双十一淘金币任务

入口为 **淘宝首页 → 领淘金币 → 去赚淘金币**。当前活动页也可能显示“去赚金币”，两个文案均支持。脚本每次运行先重新启动淘宝，再逐步识别入口，进入“今日速赚…淘金币”任务面板后执行。

```powershell
rtk proxy py -3 淘金币任务.py
rtk proxy py -3 淘金币任务.py enter
rtk proxy py -3 淘金币任务.py scan
rtk proxy py -3 淘金币任务.py run --max-tasks 10
```

- 默认执行最多 30 次；`enter` 仅导航，`scan` 只识别当前页并输出任务。
- 沿用项目 OCR 服务配置。导航和任务定位均通过 OCR，不使用固定坐标或 WebView 控件树。
- 支持上方“+金币”奖励入口及“更多专享福利”中的文字按钮；按屏幕比例配对任务标题和入口，并读取说明中的秒数、分钟数及进度。
- 支持到访、浏览、直播、视频及明确领取按钮。未知任务、答题、三商品点击、购买、授权、邀请等任务跳过；执行中落到外部 App 不进行浏览。
- 每次执行前重新定位任务，返回后复查。只有任务进度增长或同一任务行显示“已完成 / 已领取”才计为确认完成；入口消失不当作到账。
- 未确认到账的同项任务最多尝试两次；连续三轮没有可执行项结束。返回失败或丢失任务面板时停止。
- 本脚本对应金币任务面板；`tools/taobao_energy.py` 对应“去赚能量”，保持独立。

已按 2026 年 10 月 28 日真机 OCR 布局添加回归测试。活动改版导致标题和按钮无法识别时会停止，需要更新识别规则。
